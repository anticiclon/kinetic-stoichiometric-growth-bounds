# Kinetic–Stoichiometric Growth Bounds in Self-Amplifying Reaction Networks

Code accompanying the paper *"Optimizing Kinetic–Stoichiometric Growth Bounds
in Self-Amplifying Reaction Networks"* (V. Blanco, G. González).

The paper extends the Maximum Amplification Factor (MAF) framework of
[gonzalez2024maf] with the kinetic norm bound of [gagrani2026topological],
and introduces an exact parametric-sweep algorithm (Algorithm 3) for
maximizing the kinetic--stoichiometric growth bound
$(\alpha^*-1)\,\|\mathbb{S}^-\|_\kappa$ over self-amplifying subhypergraphs.

## Repository structure

```
src/            core library + all experiment scripts (see below)
cluster/        PBS job script for the scalability study on a cluster
scenarios/       generated .txt scenario files (created at runtime, empty here)
output/          experiment results, logs, CSVs (created at runtime, empty here)
figures/         generated plots (created at runtime, empty here)
```

Everything under `src/` uses flat imports (e.g. `from algorithm_3 import ...`),
so `src/` needs to be on `PYTHONPATH`. Every script's output paths
(`figures/`, `output/`, `scenarios/`) are resolved relative to the **repo
root** using `__file__`, not the current working directory — so they can be
run from anywhere (repo root, `src/`, or via `runfile(...)` in Spyder with
`wdir` set to `src/`) and outputs will always land in the correct top-level
folders.

### Core library (`src/`)

| File | Role |
|---|---|
| `algorithm_3.py` | The proposed method: descending parametric sweep over the kinetic norm, with Dinkelbach-type generalized fractional programming and incumbent-based screening (Algorithm 3 in the paper). |
| `algorithm_2.py` | Baseline: MAF-only maximization (Maximum Amplification Factor), from [gonzalez2024maf]. Used throughout as the comparison criterion. |
| `auxiliary_functions.py` | Helpers for `algorithm_2.py` (self-sufficiency checks, connected-component decomposition, arc reporting). |
| `dynamics.py` | Balanced-growth rate $\Lambda$ (dominant eigenvalue of the linear operator $M$), and the kinetic norm $\|\mathbb{S}^-\|_\kappa$. |
| `drawing.py` | Plotting library: bipartite network diagrams of the optimal subhypergraph (`plotOptimalSubnetwork`) and Pareto-frontier plots of $\alpha^*$ vs. $\mu$ (`plot_pareto`). |
| `scenario_generator.py` | Synthetic multihypergraph generator used for the scalability study (embeds a verified self-amplifying core into random surrounding structure). |

### Experiments (also in `src/`, reproduce specific paper results)

| File | Reproduces |
|---|---|
| `examples.py` | Table `tab:tesis` (two-block designed instance) and Table `tab:oregonator_resultados` (Oregonator). |
| `experiment_4_formose_ensemble.py` | 50-realization kinetic ensemble on the formose reaction (Fig. `exp4_ensemble_*`), Section 5.1. |
| `pareto_formose.py` | Pareto frontier figure for the formose reaction (Fig. `formose_pareto`). |
| `rtca_experiment.py` | rTCA (full and minimal) and glyoxylate cycle results, Section 5.2. |
| `verify_cores.py` | Verifies the "single attainable kinetic norm" claim for rTCA/glyoxylate. |
| `scenario_generator.py` | Synthetic instance generator (see above; also used directly by `scalability_harness.py`). |
| `scalability_harness.py` | Full scalability study, Table `tab:escalabilidad`, Section 5.3. |
| `plot_scalability.py` | Generates Fig. `scalability` from the scalability CSV. |
| `drawing.py` | See above (library). |

### `experiments/`

| File | Purpose |
|---|---|
| `drawing_demo.py` | Standalone usage examples for `src/drawing.py` (network diagrams, Pareto plots). Not tied to any figure in the paper — kept separate so `drawing.py` stays a clean, dependency-light plotting library. |

### `scenarios/`

Generated `.txt` scenario files (created at runtime by `scenario_generator.py`
and `scalability_harness.py`), **plus two data files you must add manually**:

- `formose_minus.txt`, `formose_plus.txt` — stoichiometric matrices (28
  species × 38 reactions) of the formose reaction network, from Müller,
  Flamm & Stadler (*J. Cheminform.* 2022). These are chemistry data, not
  generated by any script in this repo, and are required by
  `experiment_4_formose_ensemble.py`, `pareto_formose.py`, and any figure
  from Section 5.1. Place both files directly in `scenarios/`; the loader
  resolves the path relative to the repo root regardless of the working
  directory the script is run from.

| File | Purpose |
|---|---|
| `run_scal.pbs` | PBS job script for running `scalability_harness.py` on a cluster with a job array over instance sizes. Adjust the queue name, walltime, and Gurobi license path to your own cluster before use. |

## Requirements

- Python ≥ 3.10 (developed and tested on 3.12.8)
- [Gurobi](https://www.gurobi.com/) ≥ 12.0 with a valid license (`gurobipy`)
- `numpy`, `networkx`, `matplotlib`

```bash
pip install numpy networkx matplotlib gurobipy
```

Optional, for nicer network layouts in `drawing.py`:
```bash
pip install pygraphviz   # or: pip install pydot
```
(falls back to `networkx.spring_layout` if unavailable)

## Reproducing the results

Every script resolves `figures/`, `output/`, and `scenarios/` relative to the
repo root regardless of your working directory, so you can run these from
the repo root, from `src/`, or from Spyder with `wdir` set to `src/` —
whichever fits your workflow.

**Analytical examples (Section 4):**
```bash
python src/examples.py
```

**Formose reaction (Section 5.1):** requires `scenarios/formose_minus.txt`
and `scenarios/formose_plus.txt` (see the `scenarios/` section above — these
are not generated by any script and must be added manually).
```bash
python src/experiment_4_formose_ensemble.py   # ensemble tightness + selection sensitivity
python src/pareto_formose.py                  # Pareto frontier figure
```

**rTCA and glyoxylate cycles (Section 5.2):**
```bash
python src/rtca_experiment.py     # no Gurobi needed — closed-form + eigenvalues
python src/verify_cores.py        # uses Gurobi, small networks (7-11 species)
```

**Scalability study (Section 5.3):**
```bash
python src/scalability_harness.py    # local run, all sizes
# or, on a PBS cluster (one job per instance size):
qsub cluster/run_scal.pbs
# then, after all array tasks finish:
python src/plot_scalability.py output/scal_final.csv
```
